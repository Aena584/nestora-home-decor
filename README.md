# NESTORA 🏡

### Make Space Feel Like Home.

NESTORA is a premium home décor and interior lifestyle e-commerce website designed to bring warmth, elegance, and sophistication into modern living spaces.

## ✨ Features

* Elegant and responsive user interface
* Home décor and furniture collections
* Product browsing and detailed product pages
* Product search, filtering, and sorting
* Shopping cart and wishlist
* Product categories and curated collections
* Modern animations and interactive elements
* Responsive design for desktop, tablet, and mobile
* Checkout interface

## 🛋️ Product Collections

* The Living Edit
* The Serenity Collection
* The Luxe Living Edit
* Bedroom Haven
* The Artisan Edit
* Lighting Studio
* Wall Stories
* The Minimalist Collection
* Outdoor Living

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* C# / ASP.NET Core (if implemented)
* MySQL (if implemented)

## 🎯 Project Goal

The goal of NESTORA is to create a visually appealing and user-friendly online shopping experience for customers looking for stylish home décor, furniture, lighting, and interior accessories.

## 📱 Responsive Design

NESTORA is designed to provide a consistent browsing experience across desktop computers, tablets, and mobile devices.
